# 📡 Startup Daily Digest — n8n AI Pipeline

> 每天早上自动从 9 个中文科技媒体抓取新闻，经 LLM 多轮筛选、去重、分类后，输出一份结构化的行业日报。

## 痛点

关注初创企业的产品发布和融资动态，需要每天浏览大量媒体——36氪、钛媒体、IT之家、爱范儿、少数派、雷锋网……信息分散、重复多、噪音大。手动整理一份日报至少需要 1-2 小时。这个工作流把整个流程压缩到全自动、零人工。

## 工作流架构

```
Schedule Trigger (定时触发)
    │
    ├── 钛媒体 (RSS)
    ├── 36氪 · 消费电子 (RSS)
    ├── IT之家 (RSS)
    ├── 爱范儿 (RSS)
    ├── 少数派 (RSS)
    ├── 雷锋网 · 消费电子 (RSS)
    ├── 钛媒体 · 机器人板块 (RSS)
    ├── 雷锋网 · 机器人 (RSS)
    └── 36氪 · 机器人 (RSS)
          │
          ▼
    Merge (合并全部数据流)
          │
          ▼
    DeepSeek: 判断是否为中国相关新闻 → 过滤
          │
          ▼
    DeepSeek: 统一日期格式 (LLM替代正则，覆盖所有格式)
          │
          ▼
    筛选今日新闻 → 翻译成英文 → 整理统一字段
          │
          ▼
    DeepSeek: 语义去重 (跨源相同事件合并)
          │
          ▼
    按版块分类 → 删除标题重复项
          │
          ▼
    DeepSeek: 结构化输出 (标题/日期/内容/影响板块/市场情绪/分析逻辑)
          │
          ▼
    Code in JavaScript: 格式化
          │
          ▼
    输出到日报数据表
```

## 核心设计思路

- **9 路 RSS 并行抓取**：覆盖消费电子和机器人两大赛道，每路限制 3 条最新文章避免信息过载
- **LLM 替代正则做日期标准化**：不同媒体的日期格式五花八门，用正则永远无法穷尽，直接让 DeepSeek 统一处理
- **多轮 LLM 过滤**：中国新闻判断 → 今日筛选 → 语义去重 → 板块分类 → 结构化输出，层层收窄
- **结构化输出**：最终每条新闻输出为：标题、日期、内容摘要、影响板块、市场情绪（利好/利空/中性）、分析逻辑

## 使用方法

### 1. 导入工作流

1. 打开你的 n8n 实例
2. 点击左上角 **⋯** → **Import from File**
3. 选择 `startup_news.json`

### 2. 配置凭证

导入后需要重新绑定以下凭证：

- **DeepSeek API Key**：工作流中有 4 个 DeepSeek 节点，需要在 n8n 的 Credentials 中添加你的 DeepSeek API Key，然后逐个绑定
- **飞书凭证**：用于将日报输出到飞书多维表格，需配置飞书应用的 App ID 和 App Secret
- **Google Cloud 凭证**：用于翻译等相关服务，需配置 Google Cloud 的 Service Account 或 API Key

### 3. 运行

- 手动点击 **Execute Workflow** 测试
- 或激活 Schedule Trigger 设置每日定时运行
