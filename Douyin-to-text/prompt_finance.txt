# 开机自启配置

## 快速设置

### 1. 改路径

编辑 `scripts/start_live_monitor.bat`，改 `PROJECT_DIR`:

```bat
set PROJECT_DIR=D:\douyin-to-text
```

### 2. 测试

双击 `start_live_monitor.bat`，看到监控启动即可。

### 3. 放入启动文件夹

1. `Win + R` → `shell:startup` → 回车
2. 右键 `start_live_monitor.bat` → 发送到 → 桌面快捷方式
3. 把桌面快捷方式剪切到启动文件夹

下次开机自动运行。

## 细节

- 最小化运行: 右键快捷方式 → 属性 → 运行方式 → 最小化
- 临时停止: 关掉命令行窗口
- 取消自启: 删掉启动文件夹里的快捷方式
